# 风格样本库

**目前是空的。**

把你以前写过的东西放进来（`.txt` / `.md` / `.docx` 都行）。写新东西前会先读这里的样本，模仿你的语气、句长、用词习惯和结构偏好——而不是输出通用 AI 腔。

## 建议放什么

- **1–2 篇你最满意的**征文、散文或演讲稿
- **1 篇正式材料**：个人简介、申请文书、工作报告
- **1 篇学术文本**：论文、课程作业、文献综述

## 为什么这比规则管用

规则只能告诉我"不要写什么"，样本能告诉我"你是什么样"。句子的长短节奏、爱不爱用短句收尾、习惯怎么开头——这些只能从样本里学。

## 说明

- 文件只在本地会话里读取，不会外传。
- 样本不必是"好文章"，只要是**你写的**就有价值。
- 放进来之后，下次开始写作时会自动参照；不用额外说明。
