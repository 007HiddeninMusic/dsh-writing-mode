# 写作项目目录

按文体分四个区，一篇稿子一个文件夹。

```
projects\
├─ 征文\     文学征文、散文、演讲稿
├─ 论文\     课程论文、期刊小论文、会议短文
├─ 网文\     网络小说（设定集 / 人物卡 / 前情提要 / 分章正文）
└─ 申请\     申请表、个人简介、成就清单
```

## 命名约定

```
projects\征文\2026-03-城市记忆\
├─ 素材\      题目要求、赛事规则、参考资料、评分表
├─ 大纲\      结构、提纲、多次改稿的中间版本
└─ 成稿\      最终交付的 .md / .docx
```

论文与申请的目录结构同理，`素材\` 里放模板、文献、原表格。

## 为什么要分文件夹

- **跨会话能接上**：下次开新会话只想说"继续改《城市记忆》"，文件都在，不用重新交代背景。
- **网文尤其需要**：设定集、人物卡、前情提要、伏笔台账都要长期留存，否则写到第 30 章必然前后矛盾。
- **改稿可回溯**：`大纲\` 里保留中间版本，改坏了能退回去。

## 建议

一开始不用严格照做。直接说"新建一个征文项目"，会把文件夹和骨架建好。
