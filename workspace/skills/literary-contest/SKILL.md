# 文学征文

面向中文征文、散文、演讲稿、主题文章与比赛投稿。

## 一、动笔前必须问清

一次性问全，不要边写边问：

- **题面原文**，以及硬约束：字数上限/下限、体裁、是否命题、是否限定人称、是否要标题
- **赛事信息**：主办方、主题、截稿时间、评分标准（有评分表就请用户贴出来）
- **读者与场合**：评委 / 公众 / 现场朗读
- **必须包含**与**禁止出现**：真实人名地名机构名、避讳话题、指定元素
- **可选**：用户旧作一篇（若 `style-samples\` 里有，先读）

## 二、拆题

1. 把题面里的硬约束**逐条抄成清单**，写作全程对照。
2. 找**题眼**：题目里哪个词是必须被回应的，全文要围着它转。
3. 判断**体裁契约**：
   - 散文 → 感受与细节，结构可以松，情绪要真
   - 演讲稿 → 节奏与听众，句短、有呼叫与停顿、能读出声
   - 议论文 → 立论与论据，观点要能被反驳
   - 主题征文 → 切题第一，文采第二；跑题的高分文笔也是零分

## 三、对齐评分标准

常见维度与抓手：

| 维度 | 抓手 |
|---|---|
| 立意 | 角度是否新、是否真的切题、有没有超出常识的判断 |
| 结构 | 起承转合、递进、对照；层次之间要有关系，不是并列堆砌 |
| 语言 | 准确、有质感、有个人声音；无套话 |
| 细节 | 具体可感的场景、物件、动作、数字 |
| 思想 | 有真实体会，不是口号 |

**有评分表就按权重分配篇幅**，不要平均用力。评委只看几分钟，把力气花在权重最高的维度上。

## 四、结构与节奏

- **开头**（三选一）：具体场景切入 / 一个反常判断 / 一件小物件。禁用"随着社会的发展""在这个…的时代""有人说…"。
- **中段**：每段完成一次推进，段与段之间是因果或转折关系。写完自查：调换任意两段的顺序，文章是否还成立？成立就说明结构是假的。
- **结尾**：回扣题眼，落在具体处。不上价值口号，不写"让我们一起…"。
- **字数**：写到上限的 90%–98%，留一段可删的余量。

## 五、语言负面清单

**删**：空泛形容词（伟大、美好、深刻、震撼）、万能句（"生活总有它的答案"）、成语堆砌、连续排比超过三句、比喻套比喻。

**改**：
- 抽象 → 具体："日子很辛苦" → "手上起了三处茧，冬天一碰水就裂"
- 判断 → 证据："他很善良" → "他把伞塞给我，自己跑进雨里"
- 抒情 → 动作

**句式**：长短句交错；一段不超过 5 行；相邻段落首句不要用同一句式。

## 六、引用与事实核查（硬规则）

- 任何引文、名言、典故、数据、事例，**先用 `web_search` 核实**，记录来源链接。
- 核实不到就换一个确实能站住的表达，或标注 `【待补：需核实出处】`。
- **绝不**凭记忆写"某位作家曾说""有研究表明"。
- 用户提供的事例照用，但**不添加用户没说过的细节**（获奖、职务、数字、评价）。

## 七、交付

- **默认**：对话里给 Markdown 正文 + 字数统计。
- **投稿/正式提交**：生成 `.docx`（用 `office-docx` 技能），按赛事要求排标题、正文、署名。
- **用户拿不定主题时**：先给 3 个不同切入的开头（各 100 字内），选定后再展开。

## 八、交稿前自检

- [ ] 硬约束逐条通过（字数、体裁、人称、格式、命题要求）
- [ ] 题眼被明确回应，没有跑题
- [ ] 每处引用都有可点开的来源，或已标 `【待补】`
- [ ] 没有用户未提供的具体事实
- [ ] 段落顺序不可随意调换（结构是真的）
- [ ] 删掉任意一段，文章是否仍成立？成立的那段在凑数
- [ ] 通读一遍，改掉读起来像 AI 写的句子
