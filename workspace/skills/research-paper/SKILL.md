# 科研小论文

面向课程论文、期刊小论文、会议短文、摘要与文献综述。

## 一、动笔前必须问清

- **学科与题目**；是课程论文、期刊投稿还是会议短文
- **目标字数与语言**（中文 / 英文 / 中英双语摘要）
- **引用格式**：GB/T 7714 / APA / IEEE / 期刊模板文件（有模板就请用户上传）
- **数据来源**：用户已有数据？实验记录？公开数据集？**没有数据就不要假装有**
- **已有材料**：草稿、提纲、参考文献清单
- **截稿时间**与是否要盲审格式（去掉作者信息）

## 二、结构（IMRaD 及变体）

- **标题**：对象 + 方法 + 结果方向。避免"…的研究""…的探讨"这类空词堆叠。
- **摘要**（200–300 字）：背景一句 → 方法一句 → 结果含关键数字两句 → 结论一句。不写"本文具有重要意义"。
- **关键词** 3–6 个，取自标题与摘要的核心名词。
- **引言**：领域现状 → **已有工作的缺口** → 本文做什么、贡献几点。缺口必须来自真实文献，不能自己造。
- **方法**：**可复现**。数据来源、样本量、工具与版本、步骤、评价指标。别人照做能重复。
- **结果**：图表先行，正文只解释图表说了什么，**不在此处讨论原因**。
- **讨论**：结果的含义 → 与已有工作的对比 → **局限性** → 后续工作。不写局限性反而可疑。
- **结论**：3–5 句，不引入新信息。
- **参考文献**：与文内引用一一对应。

## 三、引用红线（最重要）

- 只用**本次实际检索到、能给出链接或 DOI** 的文献，用 `web_search` / `web_fetch` 查证。
- **绝不编造**作者、年份、期刊名、卷期页码、DOI。"记忆里好像有这篇"一律不算。
- 查不到就写 `【待补文献：需检索……】`，并在交付说明里列出待补清单。
- 不要把综述里的**二手转述**当成原文结论；能读到原文摘要再引用。
- 引用格式统一，编号与文内标注一一对应；中英文文献格式分别遵循所选标准。

## 四、图表与公式

- **图**：题注在图下方；**表**：题注在表上方；编号连续。
- 正文必须引用每一张图表（"如图 1 所示"），没有正文引用的图表删掉或补引用。
- 单位用国际单位制，数字与单位间留空格；同一量的有效数字前后一致。
- **公式**：独立成行并编号；符号首次出现时定义；变量斜体、单位正体（Markdown 里用文字说明，导出 docx 时保持）。

## 五、语言

- 客观陈述。禁用"我认为""众所周知""非常重要""具有重要意义"。
- 时态：方法与结果用过去时，结论与普遍事实用现在时（英文写作时）。
- 一段一个论点；长句拆短；避免"不仅…而且…"式堆叠。
- 术语前后一致，同一概念不要换三种说法。

## 六、交付

- **默认**：对话里给 Markdown（标题、摘要、关键词、正文、参考文献）。
- **需要提交**：生成 `.docx`，按模板设置标题层级、图表题注、参考文献格式（用 `office-docx` 技能与内置 Python）。
- 交付时**附一份短清单**：完成字数、待补文献、未验证的数据点、所做的格式假设。

## 七、交稿前自检

- [ ] 每条参考文献都能点开（链接/DOI 已验证），没有一条是"凭印象"写的
- [ ] 文内引用与文末列表数量、编号完全一致
- [ ] 每张图表都被正文引用
- [ ] 数据全部来自用户或可核查来源，**没有我编造的数字**
- [ ] 摘要里的数字与正文一致
- [ ] 局限性写了，结论没有过度宣称
- [ ] 字数符合要求；盲审要求（去作者信息）已满足
