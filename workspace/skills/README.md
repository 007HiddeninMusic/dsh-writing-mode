# 写作技能（skills）

技能是**按需加载**的：模型判断当前任务属于哪一类，才去读对应的 `SKILL.md`。平时不占用上下文。

## 已建（5 个）

| 技能 | 触发场景 |
|---|---|
| `literary-contest` | 征文、散文、演讲稿、主题文章、比赛投稿 |
| `research-paper` | 课程论文、期刊小论文、会议短文、摘要、文献综述 |
| `web-novel` | 网络小说、连载、续写、设定管理 |
| `application-forms` | 申请表、报名表、推荐表、任何有字段和字数上限的表单 |
| `personal-profile` | 个人简介、自我介绍、成就清单、奖项申报 |

## 怎么加一个新技能

在 `skills\` 下新建一个目录，里面放 `SKILL.md`：

```markdown
---
name: 技能名（小写字母和连字符，与目录名一致）
description: 一到三句话，说清「做什么」和「什么时候该用它」，把用户可能说的中文触发词写进去。这段话是模型决定要不要加载这个技能的唯一依据。
---

# 正文标题

正文写规则、流程、清单、模板。
```

改完**下次会话生效**，不需要改模式配置、也不需要重启。

## 写作注意

- `description` 写得越具体，越容易被正确触发；只写"写作助手"这种模糊描述会导致该加载时不加载。
- 正文用清单和表格，规则要可执行（"删掉空泛形容词"优于"注意语言质量"）。
- 事实类红线（不许编造引用/数据）写在 `AGENTS.md` 里，技能里只做该文体的具体化。
- 加完新技能，跑一次 `_tools\` 里的 frontmatter 校验，确认没有格式错误（格式不对的技能会被静默忽略）。

## 共用工具

技能里引用到的工具都在 `_tools\`：

- `wordcount.py` —— 四种字数口径（汉字 / 汉字+标点 / 含空格字符 / 中英词数），支持 `.md` `.txt` `.docx`
- `citations-template.md` —— 引用台账模板
