# 写作工作区

这个目录就是「写作模式」的工作根目录。把 DSH 会话的工作目录设在这里，模式才会读到 `AGENTS.md` 和 `skills/`。

## 首次使用

1. `facts/个人事实库.template.md` → 复制一份为 `facts/个人事实库.md`，填上你的真实经历
2. 想让写出来的东西像你：把几篇旧作丢进 `style-samples/`
3. 新建会话 → 选「写作模式」→ 工作目录选**本目录**

## 目录

| 目录 | 用途 |
|---|---|
| `AGENTS.md` | **规则手册**。所有文体通用的规则都在这里，改完下次会话生效，不用碰配置、不用重启 |
| `skills/` | 5 个文体技能，按需加载 |
| `style-samples/` | 风格样本库。放你的旧作，写之前会先读 |
| `facts/` | 个人事实库。申请材料、简介的唯一事实来源 |
| `_tools/` | 字数统计（四口径）、引用台账模板、两个校验脚本 |
| `projects/` | 分文体存放项目：征文 / 论文 / 网文 / 申请 |

## 规则已经写死了这几条

1. **无源不引** —— 引用、文献、数据只用检索到并能给链接的来源；查不到就留 `【待补】`；每处引用登记进 `引用台账.md`，台账里没有的不许进正文
2. **无据不写** —— 你的经历、数字、奖项只用你提供的内容，缺的留占位符
3. **动笔前先反问** —— 读者、字数、体裁、截稿、必含项、禁忌，一次问全
4. **改稿定点修改** —— 不全文重写，只动你指出的地方，附「原文 → 改为 + 理由」
5. **字数用工具数** —— 不估，四种口径随时报
6. **交付** —— 默认 Markdown + 字数；投稿/正式材料给 `.docx`

详细版见 `AGENTS.md`。

## 常用说法

- 「帮我写一篇 1500 字的征文，题目《…》，主办方要求…」
- 「把这份数据写成课程论文，6000 字，GB/T 7714 引用格式」
- 「根据 facts 写一份一页纸的个人简介，第三人称」
- 「接着第 12 章往下写，单章 2500 字」
- 「把这份申请表回填一下」（把原表格一起给我）
- 「只改第三段，别动其他的」

## 已知限制

- **PDF 导出与渲染排版质检需要 danger-full-access 权限**，否则报 `spawn EPERM`。生成 `.docx` 不需要。
- 模式不能指定模型，模型在会话里手选。
